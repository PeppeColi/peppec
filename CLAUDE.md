# PEPPEC engine

- Use the terms of [docs/glossary.md](docs/glossary.md) in code, comments, docs, issues and pull requests; do not invent synonyms. A new term, or a changed meaning, updates the glossary in the same pull request.
- A host's `GLOSSARY.md` is the domain of the host's application, not PEPPEC's: never mix the two.
- README.md, docs/ and examples/ are the single source of how PEPPEC works: keep them current in every pull request.
